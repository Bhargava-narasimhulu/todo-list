# 📝 To-Do List

This is my first JavaScript project. I built this To-Do List application to practice HTML, CSS, JavaScript, Git, and GitHub.

## Features

* Add a new task
* Delete a task
* Mark a task as completed
* Save tasks using Local Storage
* Automatically load saved tasks after refreshing the page

## Technologies Used

* HTML
* CSS
* JavaScript
* Local Storage
* Git
* GitHub

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
